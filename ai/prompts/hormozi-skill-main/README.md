## Instalacion

### Como Skill en Claude (Cowork)

1. Descarga el archivo `.skill` desde releases
2. Abrelo en Claude y presiona "Guardar habilidad"
3. Listo — la skill se activa automaticamente cuando pidas cualquier activo de marketing

### Instalacion Manual

Copia la carpeta `skills/hormozi-marketing/` a tu directorio `.claude/skills/`.

## Frameworks Principales

### La Ecuacion de Valor (Base de Todo)

```
              Resultado Sonado x Probabilidad Percibida
Valor = ──────────────────────────────────────────────────
              Tiempo de Espera x Esfuerzo y Sacrificio
```

Cada activo maximiza el numerador y minimiza el denominador.

### La Grand Slam Offer

Una oferta tan buena que el cliente se siente tonto si no la acepta. Construida con: Resultado Sonado + Vehiculos de Entrega + Stack de Bonos + Garantia + Escasez/Urgencia + Nombre M-A-G-I-C.

### Los Core Four (Generacion de Leads)

1. **Alcance Calido** — Gente que ya te conoce
2. **Alcance Frio** — Desconocidos, uno a uno
3. **Contenido** — Uno a muchos, gratis
4. **Ads Pagados** — Uno a muchos, de pago

Mas los Lead Getters: Clientes (referidos), Empleados, Agencias, Afiliados/Socios.
