Follow the Lead Magnet Framework:

2. Choose the type (checklist, template, mini-course, calculator, free trial, community, quiz)
3. Name it using the formula: "The [Number]-[Timeframe] [Result] [Container]"
4. Design the content outline (consumable in under 20 minutes)
5. Write the opt-in page copy (headline, sub-headline, bullet points, CTA)
6. Create the 5-email follow-up nurture sequence
7. Design the bridge to the core offer

The lead magnet must "complete but not finish" - solve one problem completely while revealing the next one that requires the paid offer.
