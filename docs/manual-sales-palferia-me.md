# Manual de uso: CRM de Ventas — sales.palferia.me

Este manual está pensado para el uso diario del CRM de ventas de PalferIA. No se necesitan conocimientos técnicos. Sigue los pasos en orden y consulta las advertencias y consejos cuando aparezcan.

---

## Acceso y login

### Cómo entrar al CRM

1. Abre tu navegador web (Chrome, Firefox o Safari).
2. Escribe en la barra de direcciones: `https://sales.palferia.me`
3. Pulsa **Enter**. Se cargará la pantalla de inicio de sesión.
4. Introduce tu email: `ripvlad@gmail.com`
5. Introduce tu contraseña y pulsa el botón **Entrar** o **Login**.

💡 Guarda `https://sales.palferia.me` en tus marcadores del navegador para no tener que escribirla cada vez.

### Qué hacer si se cierra la sesión

Si al abrir el CRM te redirige a la pantalla de login, simplemente vuelve a introducir tu email y contraseña. Las sesiones pueden cerrarse solas si pasa mucho tiempo sin actividad. No significa que haya ningún error.

⚠️ Si no recuerdas tu contraseña, contacta con el administrador del sistema para restablecerla. No hay opción de "olvidé mi contraseña" en esta versión.

## Sección Prospectos

### Qué es un prospecto

Un **prospecto** es una empresa o persona que podría convertirse en cliente de PalferIA. En esta sección gestionas toda la información de contacto, el estado de la relación comercial y las notas importantes de cada uno.

### Vista tabla vs vista kanban

El CRM permite ver los prospectos de dos formas distintas:

- **Vista tabla**: muestra todos los prospectos en filas, como una hoja de cálculo. Ideal para ver mucha información de un vistazo.
- **Vista kanban**: muestra los prospectos como tarjetas agrupadas por estado. Ideal para ver en qué fase está cada prospecto.

**Para cambiar entre vistas:**

1. Localiza los botones de vista en la parte superior de la sección Prospectos.
2. Haz clic en el icono de **tabla** (cuadrícula de filas) o en el icono de **kanban** (columnas de tarjetas).
3. La vista cambia inmediatamente, sin perder ningún dato.

💡 Usa la vista kanban cuando quieras tener una foto rápida del embudo de ventas. Usa la vista tabla cuando necesites buscar o comparar datos concretos.

### Cómo añadir un prospecto nuevo

1. Pulsa el botón **+ Nuevo** que aparece en la parte superior derecha de la sección Prospectos.
2. Se abrirá un panel o modal con el formulario de nuevo prospecto.
3. Rellena los campos que tengas disponibles (ver detalle a continuación).
4. Pulsa **Guardar** o **Crear** para que el prospecto quede registrado.

### Campos del formulario de prospecto

A continuación se explica qué va en cada campo:

| Campo | Qué escribir |
|---|---|
| **Nombre** | Nombre de la empresa o persona de contacto |
| **Municipio** | Ciudad o pueblo donde está ubicado el prospecto |
| **Sector** | Sector de actividad (ej: hostelería, retail, servicios) |
| **Score** | Puntuación de 0 a 100 que indica el potencial del prospecto (100 = máximo interés) |
| **Estado** | Fase actual en el proceso de venta (ver lista de estados más abajo) |
| **Proyecto** | A qué proyecto de PalferIA pertenece: **COM-studio** o **ME-sport** |
| **Email** | Correo electrónico del contacto |
| **Teléfono** | Número de teléfono (con prefijo, ej: `34612345678`) |
| **Socios estimados** | Número aproximado de socios o empleados de la empresa |
| **Último contacto** | Fecha en que se habló con ellos por última vez |
| **Próxima acción** | Qué tienes que hacer next (ej: llamar el martes, enviar propuesta) |
| **Notas** | Cualquier observación relevante: quién atiende, horarios, intereses, etc. |

💡 El campo **Score** te ayuda a priorizar. Ponle un 80-100 a los prospectos calientes y un 20-40 a los que están en fase inicial.

⚠️ El campo **Teléfono** es importante: si no se rellena, el prospecto no aparecerá en la sección de WhatsApp para enviarle mensajes.

### Estados disponibles y su significado

Los estados reflejan en qué punto del proceso de venta está cada prospecto. Deben actualizarse cada vez que avanza la relación:

| Estado | Significado |
|---|---|
| **Identificado** | Se ha localizado como posible cliente, pero aún no se ha contactado |
| **Contactado** | Se le ha enviado un primer mensaje o llamada, sin respuesta aún |
| **Esperando respuesta** | Se ha hablado con él y está pendiente de responder |
| **Llamada agendada** | Hay una reunión o llamada pactada con fecha |
| **Propuesta enviada** | Se le ha enviado una propuesta o informe formal |
| **Negociando** | Está revisando la propuesta y hay conversación activa de precio/condiciones |
| **Cerrado** | Acuerdo firmado y cliente activo |
| **Descartado** | No tiene interés o no encaja como cliente |
| **Canal alternativo** | Se le va a contactar por otro canal (evento, referido, etc.) |

💡 Actualiza el estado después de cada interacción. Así el kanban refleja la realidad del pipeline en todo momento.

### Cómo editar un prospecto

1. Localiza el prospecto en la tabla o en el kanban.
2. Haz clic en el **icono de lápiz** que aparece en la fila o en la tarjeta del prospecto.
3. Se abrirá el mismo formulario con los datos actuales.
4. Modifica los campos que necesites.
5. Pulsa **Guardar** para confirmar los cambios.

### Cómo eliminar un prospecto

1. Localiza el prospecto que quieres eliminar.
2. Haz clic en el **icono de papelera** que aparece en la fila o tarjeta.
3. El sistema pedirá una confirmación. Lee el mensaje y pulsa **Confirmar** o **Eliminar**.

⚠️ La eliminación es permanente. Una vez borrado, el prospecto no se puede recuperar. Si solo quieres archivarlo, cambia su estado a **Descartado** en vez de eliminarlo.

### Filtrar prospectos por proyecto

Si gestionas más de un proyecto (COM-studio y ME-sport), puedes filtrar la lista para ver solo los prospectos de uno:

1. Localiza el selector de **Proyecto** en la barra superior de la sección.
2. Elige **COM-studio** o **ME-sport** según necesites.
3. La lista se actualiza automáticamente mostrando solo los prospectos de ese proyecto.
4. Para ver todos de nuevo, selecciona la opción **Todos** o deja el filtro en blanco.

### Kanban: gestión por columnas

En la vista kanban, cada columna representa un estado del proceso de ventas. Cada prospecto aparece como una tarjeta dentro de su columna correspondiente.

**Para cambiar el estado de un prospecto desde el kanban:**

1. Haz clic en el **icono de lápiz** de la tarjeta que quieres mover.
2. En el formulario que se abre, cambia el campo **Estado**.
3. Pulsa **Guardar**. La tarjeta se moverá automáticamente a la nueva columna.

💡 Si el kanban permite arrastrar tarjetas entre columnas, puedes hacerlo directamente sin abrir el formulario. Comprueba si esta función está disponible en tu versión.

## Sección WhatsApp

### Qué es una sesión de WhatsApp

Una **sesión** representa un número de WhatsApp conectado al CRM. Para poder enviar y recibir mensajes desde el CRM, primero hay que crear y conectar una sesión con tu número de WhatsApp Business.

### Cómo crear una sesión nueva

1. Ve a la sección **WhatsApp** en el menú lateral.
2. Pulsa el botón **+ Nueva sesión**.
3. Escribe un **nombre** descriptivo para identificarla (ej: `palferia-principal`).
4. Pulsa **Crear**. El sistema generará un código QR.
5. Abre WhatsApp en tu móvil.
6. Ve a **Ajustes** → **Dispositivos vinculados** → **Vincular un dispositivo**.
7. Escanea el código QR que aparece en pantalla con la cámara del móvil.
8. En pocos segundos, el estado de la sesión cambiará a **Conectado**.

⚠️ El código QR caduca en pocos minutos. Si no lo escaneas a tiempo, tendrás que solicitarlo de nuevo.

💡 Usa nombres claros para las sesiones si manejas varios números (ej: `ventas-comercial`, `atencion-clientes`).

### Estados de una sesión

| Estado | Significado |
|---|---|
| **Creada** | La sesión existe pero aún no se ha conectado ningún número |
| **QR listo** | Se ha generado el QR, esperando que el móvil lo escanee |
| **Conectado** | El número está activo y puede enviar y recibir mensajes |
| **Desconectado** | El número se ha desconectado (móvil sin internet, sesión cerrada, etc.) |

### Cómo ver el QR de una sesión existente

Si necesitas volver a escanear el QR (por ejemplo, porque el móvil perdió la sesión):

1. Localiza la sesión en la lista del panel.
2. Haz clic en el botón **Ver QR** o en la opción correspondiente de la sesión.
3. Aparecerá el código QR. Escanéalo desde el móvil como se explica arriba.

### Cómo eliminar una sesión

1. Localiza la sesión que quieres eliminar.
2. Haz clic en el **icono de papelera** o en el botón **Eliminar**.
3. Confirma la acción cuando el sistema lo solicite.

⚠️ Si eliminas una sesión, perderás el historial de mensajes asociado a ese número en el CRM. No se puede deshacer.

### Cómo enviar mensajes a prospectos desde el CRM

1. Ve a la sección **WhatsApp**.
2. En el panel izquierdo verás la lista de contactos disponibles (prospectos con teléfono guardado).
3. Haz clic en el prospecto al que quieres escribir.
4. En el área de chat que aparece a la derecha, escribe tu mensaje en el campo de texto.
5. Pulsa **Enviar** o la tecla **Enter**.

⚠️ Solo aparecen en la lista los prospectos que tienen un número de teléfono guardado en su ficha. Si un prospecto no aparece, ve a la sección Prospectos, edita su ficha y añade el teléfono.

💡 Antes de enviar un mensaje, asegúrate de que la sesión de WhatsApp está en estado **Conectado**. Si no lo está, los mensajes no se enviarán.

## Sección Propuestas

### Qué son las propuestas

Las **propuestas** son informes HTML personalizados que se generan para cada prospecto. Presentan de forma visual y profesional la oferta de PalferIA adaptada a las necesidades del cliente.

### Cómo se visualizan

Las propuestas se muestran en formato de **tarjetas (grid)**. Cada tarjeta representa una propuesta generada para un prospecto.

### Cómo abrir una propuesta

1. Localiza la propuesta que quieres ver en el grid.
2. Haz clic en ella o en el botón de apertura.
3. La propuesta se abrirá en una **nueva pestaña** del navegador, lista para compartir o revisar.

💡 Puedes copiar la URL de la nueva pestaña y enviársela directamente al prospecto por email o WhatsApp.

## Sección Log

### Qué es el log de actividad

El **log** es un registro cronológico de todas las acciones comerciales que se realizan: llamadas, emails enviados, mensajes de WhatsApp, reuniones, etc. Sirve para tener una trazabilidad completa de la actividad de ventas.

### Cómo añadir una entrada al log

1. Ve a la sección **Log** en el menú lateral.
2. Pulsa el botón **+ Añadir entrada**.
3. Rellena los campos del formulario:
   - **Fecha**: el día en que se realizó la acción (por defecto aparece la fecha de hoy)
   - **Proyecto**: COM-studio o ME-sport
   - **Nombre prospecto**: el prospecto con el que tuviste la interacción
   - **Acción**: qué hiciste (ej: "Llamada de presentación", "Envío de propuesta")
   - **Resultado**: qué ocurrió o cuál fue la respuesta (ej: "Interesado, pide más info", "No contestó")
4. Pulsa **Guardar** para registrar la entrada.

### Filtrar el log por proyecto

1. Localiza el selector de **Proyecto** en la parte superior de la sección Log.
2. Selecciona **COM-studio** o **ME-sport** para ver solo las entradas de ese proyecto.

### Cuándo usar el log

Registra una entrada en el log **después de cada interacción** con un prospecto:

- Tras enviar un email
- Tras realizar o recibir una llamada
- Tras enviar un mensaje de WhatsApp importante
- Tras celebrar una reunión o videollamada
- Tras enviar una propuesta

💡 El log es tu memoria comercial. Si en algún momento alguien pregunta "¿cuándo hablamos con Tecniluispa y qué dijeron?", la respuesta estará aquí.

⚠️ No esperes días para registrar las interacciones. Hazlo en el momento o justo después, mientras recuerdas los detalles.

## Actualizar el CRM (para cuando se hacen cambios técnicos)

Esta sección es relevante si se realizan cambios en el código o la configuración del CRM.

### Proceso de despliegue

Cuando se modifica algún archivo del proyecto, el proceso para publicar los cambios es:

1. Abre la terminal en el ordenador donde está el código.
2. Ejecuta los siguientes comandos uno a uno:

```bash
git add .
git commit -m "Descripción breve de qué se cambió"
git push
```

3. GitHub recibirá los cambios y lanzará automáticamente el proceso de despliegue (**GitHub Actions**).
4. En aproximadamente **60 segundos**, los cambios estarán publicados en `https://sales.palferia.me`.

💡 No hace falta reiniciar nada ni entrar a ningún servidor. El despliegue es completamente automático una vez que se hace el `git push`.

⚠️ Si no tienes acceso al código o a la terminal, comunícalo al administrador técnico. No intentes modificar archivos del servidor directamente.
